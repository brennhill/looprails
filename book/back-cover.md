## Blurb

The agent gives a convincing answer. But did the database change? Did the citation support the claim? Did the patch solve the problem—or merely charm the test?

*Measure Twice, Prompt Once* shows product and engineering teams how to turn those awkward questions into a working evaluation loop.

Inside, you will learn how to:

- read real failures without drowning in traces;
- build tasks and graders around the evidence that matters;
- compare changes without statistical theater;
- connect CI, release gates, and production feedback; and
- give the loop an owner, a cadence, and a budget.

Built around four published evaluation programs and one complete fictional eval loop, with runnable companion artifacts, statistical recipes, thirteen exercises, sixteen templates, and a 30-day minimum viable eval-loop plan.

## Author bio

Brenn Hill is a software engineer, engineering leader, and published author. He teaches AI-augmented development practices and builds tools for verification, agent loops, and human oversight.
